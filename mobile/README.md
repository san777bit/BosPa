# BosPa Mobile (React Native / Expo)

Мобильное приложение для отслеживания загруженности общественного транспорта в Алматы в реальном времени.

Дизайн разработан в соответствии с референсом логотипа **BosPa**: изумрудно-мятная цветовая гамма, индикатор наполненности салона (зелёный/жёлтый/красный), отображение пассажиров и дружелюбный интерфейс.

---

## 🚀 Возможности

1. **Правильная интерактивная карта (OpenStreetMap / CartoDB Voyager)**
   - Реальные трассы маршрутов Алматы (Троллейбус №7, Автобус №38А).
   - Точные координаты всех остановок.
   - Живые анимированные автобусы и троллейбусы, плавно движущиеся по маршруту с направлением движения (bearing), скоростью и индикатором загруженности.

2. **Индикация загруженности (по мотивам логотипа)**
   - 🟢 **Свободно** (есть сидячие места)
   - 🟡 **Плотненько** (только стоя, но свободно)
   - 🔴 **Не влезешь** (салон битком)
   - Фирменный датчик загруженности в виде лобового стекла с силуэтами пассажиров и верхним светофором.

3. **Карточка остановки и борта**
   - Точный расчет ETA (времени прибытия).
   - Скорость борта и количество пассажиров онлайн.
   - Кнопка **«Отметиться»** с начислением баллов **+10 B**.

4. **Поиск и список остановок**
   - Быстрый поиск по названию улицы/остановки.
   - Центрирование карты на выбранной остановке.

## 📱 Запуск приложения

Перейдите в папку `mobile`:

```bash
cd mobile
```

### Запуск в браузере (быстрый предпросмотр):
```bash
npx expo start --web
```

### Запуск на телефоне (Android / iOS через Expo Go):
```bash
npx expo start
```
Отсканируйте появившийся QR-код камерой телефона (iOS) или в приложении **Expo Go** (Android).
